## 📱 모바일 스마트폰 접속 방법

PC와 동일한 Wi-Fi(공유기)에 스마트폰을 연결한 뒤 아래 주소로 접속하면 모바일 전용 UI로 최적화되어 열립니다:

* **모바일 접속 주소:** **`http://192.168.0.50:3000`**
* **QR 코드 접속:** 웹 브라우저([http://localhost:3000](http://localhost:3000)) 우측 상단의 **[📱 모바일 접속(QR)]** 버튼을 누른 뒤, 스마트폰 기본 카메라로 QR 코드를 비추면 즉시 실행됩니다.

### 📲 모바일 전용 기능
* **모바일 네이티브 탭 전환:** [설정] ↔ [카톡 뷰 (미리보기)] 탭 지원
* **원터치 브리핑 생성:** 하단 플로팅 바에서 엄지손가락으로 원클릭 생성
* **카카오톡 앱 직접 연동:** 버튼 클릭 시 스마트폰의 카카오톡 앱으로 즉시 연결 및 공유
* **홈 화면에 추가 (PWA):** 스마트폰 브라우저 메뉴에서 '홈 화면에 추가'를 누르면 실제 앱처럼 전체화면으로 사용 가능

3. **[Web 플랫폼 등록]** 클릭 후 사이트 도메인에 `http://localhost:3000` 추가
4. **[카카오 로그인]** 활성화 상태를 **ON**으로 변경하고, [동의항목]에서 **'카카오톡 메시지 전송'** 권한을 활성화

   > *"매일 아침 7시 30분, 내 톡캘린더에서 오늘의 일정을 조회하고 카카오맵으로 집에서 회사까지 소요 시간을 확인해줘. 날씨와 우산 필요 여부, 추천 옷차림을 정리해서 카카오톡 나와의 채팅방으로 굿모닝 브리핑을 보내줘."*
