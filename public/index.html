PlayMCP 카카오 오픈 플랫폼 연동 가이드

PlayMCP(playmcp.kakao.com)는 카카오톡(나와의 채팅), 톡캘린더, 카카오맵 등의 카카오 핵심 서비스를 MCP 표준 프로토콜로 AI와 연결해 줍니다.

🚀 완전 자동화 아침 브리퍼 구성 3단계:
  1. playmcp.kakao.com에 카카오 계정으로 로그인합니다.
  2. '도구함'에서 카카오톡 나와의 채팅, 톡캘린더, 카카오맵 도구를 추가합니다.
  3. '연결 프롬프트 생성' 버튼을 눌러 복사한 뒤, Claude Code / ChatGPT / Cursor 에이전트에 등록하면 매일 아침 자동 브리핑이 실행됩니다!
📋 추천 AI 에이전트 프롬프트 (원클릭 복사):
매일 아침 7시 30분, 내 톡캘린더에서 오늘의 일정을 조회하고 카카오맵으로 집(역삼역)에서 회사(판교테크노밸리)까지의 실시간 소요 시간을 확인해줘. 그리고 오늘의 날씨와 우산 필요 여부, 추천 옷차림을 정리해서 카카오톡 나와의 채팅방으로 '굿모닝 브리핑' 메시지를 보내줘.

카카오 앱 키 & 도메인 설정 안내

입력해주신 카카오 앱 키(f4a85c9ad10954427600e3d692e7431c)로 웹에서 카카오 로그인 및 나와의 채팅 메시지를 직접 전송하시려면, 카카오 개발자 콘솔에서 1분 설정이 필요합니다.

🛠️ 플랫폼 웹 도메인 등록 방법:
  1. 카카오 디벨로퍼스 콘솔에 로그인합니다.
  2. [내 애플리케이션] ➡️ [앱 설정] ➡️ [플랫폼] 메뉴로 이동합니다.
  3. [Web 플랫폼 등록]을 클릭하고 사이트 도메인에 아래 두 개 주소를 등록합니다:
    • http://localhost:3000 (PC용)
    • http://192.168.0.50:3000 (모바일용)
  4. [카카오 로그인] 메뉴에서 활성화 설정 상태를 ON으로 켜고, [동의항목]에서 '카카오톡 메시지 전송(나에게 보내기)' 권한을 활성화합니다.

* 설정을 아직 안 하셨더라도 본 앱의 '카톡 공유하기' 기능과 '텍스트 복사'를 통해 카카오톡으로 즉시 활용하실 수 있습니다!
